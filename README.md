# 🔥 部落纪元 · 上古争霸 —— 双人网上对战版

原单文件 RTS「部落纪元·上古争霸」的联机改造版:**游戏形式与内容完全不变**(同样的单位/建筑/神兽/野怪/资源/操作/画面),新增**双人网上对战**:你和好友各领一个部落,加上一个 AI 部落三方混战。同时保留**单机模式**(1 玩家 vs 双 AI,与原版一致)。

- 原工程:`../nationwar`(未改动,可对照)
- 本工程:独立仓库,服务器权威模拟,无构建工具、无框架(纯 ES Modules,唯一依赖 `ws`)

---

## ✨ 玩法

- **单机模式**:选难度,1 玩家(橙·左)vs 2 个 AI(紫·右 / 青·上),与原版行为一致。
- **网上对战**:一人**创建房间**得 4 位房间码,好友**加入房间**,双方准备后房主开局。两位真人分别控制橙方与紫方,青方为 AI(难度由房主选,只作用于 AI,双方玩家完全公平)。
- 胜负:己方营火被毁即个人失败;其余两方(对方玩家 + AI)营火全部被毁才获胜。
- 断线 60 秒内可通过「重连对局」恢复;支持大厅聊天。

操作与原版一致:左键选择/框选、左键点目标下令(或右键)、WASD 移动视口、数字键 1-4 快捷建造、小地图跳转。**暂停仅单机可用**(空格);联机按空格查看房间/延迟。

## ▶️ 如何运行

需要 Node.js ≥ 18。

```bash
cd nationwar-online
npm install        # 仅安装 ws
node server.js     # 默认 8080,可用 PORT=3000 node server.js
```

- **本机试玩**:浏览器打开 `http://localhost:8080/`
  - 单机:主菜单 → 「单机 · 打双 AI」
  - 联机本机双开:两个标签页,一个创建房间、一个用房间码加入

### 和好友联机

**同一局域网(WiFi)**:启动服务器后,把 `http://<你的局域网IP>:8080/` 发给好友(服务器启动时会打印地址;macOS 可用 `ipconfig getifaddr en0` 查询)。

**公网**(三选一):
1. **VPS 部署**:任意 Linux 小主机 `node server.js`,防火墙放行端口,双方访问 `http://<服务器IP>:8080/`。
2. **PaaS**:Render / Railway / Fly.io 等直接跑 `npm start`(记得设 PORT)。
3. **内网穿透**:frp / ngrok / cloudflared 把本地端口映射出去(用 HTTPS 代理时 WebSocket 自动走 wss,本游戏已支持)。

## 🧱 架构

```
浏览器 A(房主,橙)         浏览器 B(客方,紫)
  input → 命令对象 → ws →     ↓
        Node 服务器(权威模拟)
        · Room ×N,60Hz 固定步长跑 shared/sim.js
        · 增量快照 @10Hz + 全量关键帧 @1Hz + 事件流
        · AI 部落(青)在服务器端运行
              ↓ ws ← 快照+事件
  view(插值实体,渲染落后 ~120ms)+ render/ui(原渲染层)
```

- **服务器权威**:模拟只在服务器跑,客户端只发命令、收快照,天然防作弊、无跨浏览器不同步问题。
- **单机模式**直接在浏览器内嵌同一份 `shared/sim.js`(零延迟,不联网)。
- fx/伤害数字/炮弹等瞬态视觉以**事件**随快照下发,客户端本地播放。

### 目录

```
nationwar-online/
├── server.js               # 入口:http 静态 + ws + 全局 60Hz 循环
├── src/
│   ├── server/             # rooms(房间码/回收) room(大厅/模拟/快照/重连) sanitize(入站校验/限频)
│   ├── shared/             # Node 与浏览器共用
│   │   ├── cfg.js          #   配置与纯工具(数值与原版一致)
│   │   ├── sim.js          #   createGame():全部模拟 + applyCommand(命令权威校验)
│   │   └── snapshot.js     #   全量/增量快照编码
│   └── client/             # view(双模式视图+插值) render(原 draw*) input ui
│                           # hostLocal(单机) hostNet(联机/大厅) net(ws) main(装配)
├── public/                 # index.html + style.css
└── test/                   # soak.mjs(无头模拟) net.mjs(联机回路)
```

### 协议要点

- 命令(上行):`order / rally / build / train / stance / summon / camp_return`,目标用实体 id;服务器双层校验(sanitize 形状 + sim.applyCommand 权威:所有权/资源/人口/放置)。
- 快照(下行):紧凑行数组(坐标取整),每连接缓存「上次已发」做逐行 diff;每 1 秒全量关键帧兜底;掉线重连直接全量。
- 实测带宽 ~15KB/s(约 120kbps)/客户端,一台普通机器带多个房间无压力。

## 🔧 与原版的差异(有意为之)

1. **联机对战**:2 真人 + 1 AI 三方混战;地图布局、全部数值不变。
2. **难度只作用于 AI 部落**(联机时双方玩家伤害/收入恒 1.0,保证公平;单机保留原版不对称难度)。
3. **暂停仅单机**;联机不能暂停。
4. 「建筑完成」提示只发给建造方(原版任意阵营完工都会弹提示)。
5. 战斗特效/伤害数字在联机下最多延迟一个快照间隔(≤100ms)到达。
